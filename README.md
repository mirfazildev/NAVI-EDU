# NAVI — Sun'iy intellekt asoslari (1-modul)

Math Academy usulida qurilgan namunaviy ilova (faqat front-end, ma'lumot saqlanmaydi).

- 21 mavzu, ~75 bilim nuqtasi (BN), 414 ta 4 variantli savol
- Dars oqimi: ketma-ket 2 to'g'ri → keyingi BN; ketma-ket 3 xato → dars to'xtaydi, 30 daqiqa dam (Q-605, Q-607)
- 8 ta mavzuda algoritmli prompt amaliyoti ("soxta SI", haqiqiy SI yo'q — Q-604)
- XP (X-2 darajalari), kunlik maqsad 40 XP, streak (≥10 XP/kun, haftasiga 1 muzlatish)
- Vazifani tizim tanlaydi (V-1…V-10), oraliqli takrorlash va FIRe (T-1…T-5), quiz (QZ-1…QZ-8)
- Bilim grafi ko'rinishi
- "Sinov uchun: keyingi kunga o'tish" tugmasi vaqtni 1 kunga suradi

Fayllar: `index.html`, `styles.css`, `data.js` (mavzular va BN'lar), `content/tNN.js` (savollar), `practice.js` (amaliyot tekshiruvchilari), `app.js` (dvigatel va ekranlar).
Qoidalar manbasi: Navi Global Product/Mirfazil/Arxitektura (12, 22-fayllar va 01 qarorlar).
